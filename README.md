# SSH Beacon

Windows 桌面小组件：有远程 SSH 会话连入这台电脑时，屏幕角落出现一个置顶的闪烁小黄点；没有连接时完全隐藏。

## 功能

- 入站 SSH 连接时出现，断开 6 秒后淡出
- 悬停显示来源设备与连接时长
- 可拖动，位置持久化，重启后沿用
- 托盘常驻：开机自启、重置位置、打开日志、退出
- SSH 登录成功后，托盘图标右上角出现橙红色未读点。左键单击图标，或右键选择“查看访问日志”，即可清除；重启后保留已读状态。
- 访问日志按最近访问排序，显示本地时间、来源设备、使用账号和登录次数。同一地址、同一账号前后两次登录间隔在 60 秒以内时合并提醒。悬停托盘可查看最近的访问时间和地址。
- 监控异常时显示红点

## 构建

需要 .NET Framework 4.8（Windows 10/11 自带），用系统自带的 csc 编译：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

## 使用

双击 `SshBeacon.exe` 运行，首次运行会注册开机自启（HKCU Run）。右键小点或托盘图标可修改设置。

## 检测方式

桌面黄点每 800 毫秒检查一次本机 TCP 连接表，显示 22 端口的入站连接。托盘另从 Windows 的 `OpenSSH/Operational` 事件日志读取成功登录，每 3 秒检查新增记录，因此也能提示轮询间隔内已结束的短连接。

启动时从系统日志恢复最近 7 天内最多 1000 次成功登录，窗口展示最近 200 组访问。启动时补读的记录以角标提示，运行中发现新一组访问时另发系统通知。SSH 登录记录提供访问时间、地址和账号；文件名和执行的命令需要其他审计数据。

## 文件

右键选择“查看访问日志”，每组登录和每条文件收发各显示为一张卡片，最新的在上面。

### 启用文件收发记录

在管理员 PowerShell 中运行 `Enable-SftpHistory.ps1`。脚本将默认或旧版 Beacon 子系统迁移到 `sftp-server.exe -l INFO`，备份并校验配置后重启 SSH 服务。已有 SSH 连接时会暂缓重启。恢复时可使用同目录的 `sshd_config.sshbeacon-*.bak`，核对后重启 sshd。

Windows 原生 SFTP 服务直接处理文件传输并将操作写入 `OpenSSH/Operational`。打开日志时，Beacon 按当前 Windows 账号读取最近 7 天的事件，用 SFTP 服务进程 ID 关联来源设备，根据实际读写字节区分收发。零字节操作按打开模式显示“对方请求下载”“对方请求上传”或“访问文件”。运行中收到文件关闭事件也会点亮未读角标并发出托盘通知，同一批文件合并提示。传统 SCP（`scp -O`）和通过普通 SSH 命令写入的文件只会产生相应的 SSH 登录记录。

收发卡片显示本机路径，单击可在资源管理器中选中文件。历史版本保存在 `%LOCALAPPDATA%\SshBeacon\Transfers` 的记录继续可读并沿用原清理规则。原生事件日志按 Windows 通道容量滚动，文件路径可能保留超过 7 天。
